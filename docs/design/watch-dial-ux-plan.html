The same journeys on both devices.

First use
Identify device → protected setup → approve → first useful actionWi-Fi, Gateway approval and capability readiness are separate steps. Both devices work independently.
Resume work
Home → Continue → current conversation → result in ActivityKeep the selected agent and thread. Voice is an additional path on capable hardware.
Choose an agent
Menu → Agents → permitted agent → choose or create conversationKeep the old route until success. Existing controls, results and calls retain their owner.
Control a device
Devices → target → edit draft → Apply → Waiting → reported resultTouch and rotation share one action contract. Neither changing agent nor navigating away retargets a request.
Tune this device
Settings → Display → Compact / Comfortable or text size → previewSpacing and font size are separate. Devices → This device opens the same local control state.
Understand status
Status strip → Connection / Power → repair the failed layerOn the Dial, use Settings. Unknown battery is a dash; USB alone does not establish charging.
