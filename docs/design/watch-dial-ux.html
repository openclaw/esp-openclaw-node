Quiet separators, tabular numbers, > focus and explicit on/off states. Long text stays readable and Unicode is preserved. This browser uses system mono; firmware font selection still needs raster, memory and glyph-coverage checks.

Agent is not conversation

The watch chooses an assistant, then a new or existing conversation. The Dial binds an agent to a specific control. Neither silently retargets an in-flight request. Full design and user-walkthrough findings.
