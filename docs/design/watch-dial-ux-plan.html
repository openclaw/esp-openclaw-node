DIAL / 240 × 240 / TURN + PRESS + TOUCH

The circle is the interface.

One focal item, a readable value or a short message. Use different regions for choosing, editing and reading instead of a universal central box.

Design around the whole task.

First use
Identify device → protected phone/USB setup → approve → first useful actionWi-Fi success alone is not readiness. Expired codes and rejected access have specific recovery.
Daily watch use
Home → Talk → End → Activity → read or resumeOne tap to start in the current context. Back/Home preserves a call; End closes it.
Change assistant
Conversation selector → change assistant if needed → choose thread → return HomeKeep the old selection until success. A live call requires an explicit end-and-switch decision.
Adjust the Dial
Home → Edit → turn draft → Apply → Waiting → resultTurning is local. Acknowledgment is not completion. Background results never steal the screen.
Change its control
Control → assignment → assistant → target → inspect → accepted bindingFailure keeps the old binding. Already-submitted work may still run.
Read & repair
Activity or Settings → focused content/repair → return to the same contextUse the full reader. Retain drafts, focus and identity according to the action’s actual scope.
